# J-YOUTH NEXT — 高校サッカー進路・内申基準・スカウト情報完全ガイド（情報特化版）

「スカウトへの連絡機能や外部DBは不要であり、進路・推薦・スカウト基準・練習会に関する詳しい情報が入手できればよい」というご回答に基づき、模擬的なスカウトチャット・連絡機能を廃止し、**GRANDE FC（埼玉）所属・東京都在住の中学1年生と保護者が「本当に知りたい各高校の推薦・内申・施設・寮・卒業後進路・スカウト視察＆練習会情報」を網羅的に調べ尽くせる情報特化型プラットフォーム**へとアップデートします。

### User Review & Critical Decisions

> [!IMPORTANT]
> ご回答いただいた内容を反映し、以下の通り設計を見直しました。ご確認のうえ、問題なければ「Proceed」より実装へお進みください。

- **Confirmed Decision 1（スカウト連絡機能の廃止と「スカウト・練習会情報ガイド」への刷新）**:
  - 誤解を招く「スカウトとのチャット・メッセージ送信機能」や「練習会へのダミー申込ボタン」を廃止します。
  - 代わりに、**「各高校のスカウトがいつ・どの大会（関東リーグ・クラブユース等）を視察しているか」「各高校が求める選手像・ポジション別評価ポイント」「練習会・セレクションの例年の開催時期と参加方法（クラブ経由／個人Web申込の違い）」「個別相談会で保護者が確認すべき質問リスト」**を網羅した実用的な情報ビューへ刷新します。
- **Confirmed Decision 2（外部DB不使用・シンプルで高速な情報閲覧）**:
  - Firebase等の外部データベースやログイン機能は一切設けず、アプリを開いた瞬間にすべての高校データ・内申シミュレーション・体験談・スカウト情報をストレスなく閲覧・比較できるようにします。
- **Confirmed Decision 3（収録高校データのさらなる拡充：全16校へ）**:
  - 情報収集の価値を最大化するため、これまでの10校に加えて、GRANDE FCからの進学実績や東京・埼玉からの人気が非常に高い **「聖望学園」「市立浦和（公立・文武両道）」「東海大高輪台（東京）」「桐光学園（神奈川）」「矢板中央（栃木）」「尚志（福島）」** の6校を新たに追加し、**計16校の詳細データ**を完全収録します。

### 1. Overview & Core Concept

- **What It Does**:
  1. **全16強豪校の徹底比較＆偏差値・内申フィルター**: 埼玉・東京・関東・全国の主要16校について、「どのコースが偏差値いくつか」「スポーツ推薦（単願）・併願優遇・学業特待にそれぞれ内申点がいくつ必要か」「施設・人工芝・ジムの質」「寮の有無と費用・東京からの通学ルートと所要時間」「卒業後のJリーガー輩出数と主要進学先大学」を網羅します。
  2. **「サッカーの強さ × 必要内申点・偏差値」2軸ポジショニングマップ**: 9教科の内申点を変更すると、リアルタイムにどの高校が推薦基準クリア圏内かがマップ上で可視化されます。
  3. **部活紹介動画チャプター ＆ 現役選手・GRANDE FC OB体験談**: 各高校の練習内容・施設・寮の解説と、GRANDE FC出身の先輩たちが「中1〜中3でどう内申点を上げたか」「なぜその高校を選んだか」の体験談を読めます。
  4. **スカウト視察の仕組み＆練習会・セレクション時期一覧（新設・改修）**: 連絡ツールではなく**「スカウト情報の百科事典」**として、街クラブ（GRANDE FC）から強豪校へ推薦で行く際の裏側の仕組み（スカウトが見るポイント、時期別の動き、クラブ経由と一般練習会の違い、各校の例年の練習会スケジュール）を詳しく解説します。
- **Target Audience / Persona**:
  - GRANDE FC（埼玉）でプレーし、東京都内の自宅・中学校から通う中学1年生選手とその保護者。

### 2. User Experience & Visual Design

- **Key User Flows**:
  1. **高校探索＆比較フロー**: トップ画面でエリア・偏差値レンジ・内申基準・寮の有無・GRANDE FC進学実績で高校を絞り込み ➔ カード一覧または2軸マップで比較 ➔ 最大3校を選んで並列比較テーブルで内申・施設・進路を厳密に比較。
  2. **高校詳細データ閲覧フロー**: 高校カードをクリック ➔ モーダル内の4タブ（`① 内申基準・施設・寮・コース` / `② 部活紹介動画` / `③ 現役選手・OB体験談` / `④ 卒業後の進路・スカウト基準＆練習会時期`）で1校を深掘り。
  3. **9教科内申シミュレーター＆越境受験ガイドフロー**: `進路・推薦ガイド` タブで9教科の評定を操作し、現在の内申で狙える高校とあと+1〜3で届く高校を確認 ➔ 東京在住×埼玉クラブならではの越境受験ルール（北辰テストの扱いや東京都の私立授業料軽減助成金など）を確認。
  4. **スカウトの仕組み＆練習会スケジュール確認フロー**: `スカウト・練習会情報` タブにて、各高校の「例年の練習会・セレクション開催月」「申込ルート（クラブ監督経由／Web公募）」「スカウトが重視するプレー・身体能力・内申基準」を一覧表と比較カードで確認。

- **Visual Identity & Theme**:
  - クリーンで視認性の高いライトキャンバス（`#F8FAFC` / `#FFFFFF`）に、ピッチを象徴するディープ・エメラルド（`#059669`）と引き締まったダークスレート（`#0F172A`）を組み合わせたエディトリアル・データダッシュボード。
  - 偏差値・内申点・通学時間・プロ輩出数などの数値にはすべて等幅・表組数字（`tabular-nums`）を適用し、16校のデータを美しく比較できます。

### 3. Key Product Decisions & Trade-Offs

- **Decision 1: チャット機能を廃止し「スカウト評価基準＆練習会時期データベース」へ転換**
  - *Chosen Approach*: 擬似的なチャット画面をすべて撤去し、代わりに「高校スカウトは中学1〜3年のいつ・どこを見ているのか」「各高校の練習会は例年何月に開催され、どうすれば参加できるのか」「各高校が求める選手像と内申・欠席日数の条件」を詳細にまとめた情報ページに置き換えます。
  - *Why*: ユーザー様が求めているのは「架空のチャット相手」ではなく、「実際に高校進学に向けて親子の判断材料になる正確で詳しい情報」であるためです。

- **Decision 2: 埼玉・東京・関東・全国の収録校を10校から16校へ大幅増強**
  - *Chosen Approach*:
    - **埼玉県（8校）**: 昌平、武南、西武台、立教新座、浦和学院、正智深谷、**聖望学園（追加）**、**市立浦和（公立・追加）**
    - **東京都（5校）**: 帝京、國學院久我山、駒澤大学高、実践学園、**東海大高輪台（追加）**
    - **関東・全国寮完備（5校）**: 前橋育英、市立船橋、流通経済大柏、**桐光学園（追加）**、**矢板中央（追加）**、**尚志（追加）**、青森山田、静岡学園（※計18校の充実データセット）
  - *Why*: 東京から通える私立・公立の選択肢と、寮に入って全国を目指す選択肢を漏れなく比較できるようにするためです。

- **Interactive Component & State Mapping**:
  - **高校詳細モーダルの改修**: フッターやタブから「チャットへ飛ぶ」ボタンをなくし、その高校の「スカウトが重視するポイント・例年の練習会開催時期・申込経路（クラブ推薦／Webエントリー）・個別相談会での確認ポイント」をその場で詳しく確認できるようにします。

    3. **個別相談会・練習会参加時の「保護者チェックリスト＆質問シート」**: 実際に高校の説明会や練習会に行った際、先生やコーチに確認すべき項目（特待ランクの条件、3年間の総費用、寮の空き状況、大学指定校推薦の枠など）を整理できます。
